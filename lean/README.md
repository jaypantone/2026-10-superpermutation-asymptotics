# Lean proof

See [the build guide](../BUILDING.md) for the pinned environment, the guarded
shared-storage build, standard Lake reproduction, and independent NanoDa
verification. The default target is `Precision`.

The final theorems are in [MainTheorems.lean](Quantitative/MainTheorems.lean).
[StatementAudit.lean](Quantitative/StatementAudit.lean) prints their full
types, original definitions, and axiom dependencies.
