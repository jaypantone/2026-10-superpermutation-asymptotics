# A polynomial error estimate for superpermutation length

A superpermutation on `n` letters is a word containing every permutation of
those letters as a contiguous substring. Let `L(n)` be the least possible
length of such a word. This repository proves

$$
L(n)=n!+(n-1)!+(n-2)!+2(n-4)!+O\bigl((n-4)!n^{-1/61}\bigr).
$$

Read the [manuscript](paper/manuscript.pdf), its [LaTeX source](paper/main.tex),
or the [final Lean statements](lean/Quantitative/MainTheorems.lean).
The [proof map](PROOF_MAP.md) connects the mathematical steps to the
formalization.

## The finite theorem

Put `F3(n) = n! + (n-1)! + (n-2)!` and
`C = 8 * 10^12 * 352^4`. For every integer `r >= 6` divisible by six and
every integer `n >= C * r^61`, there is an actual superpermutation `w` with

$$
r|w|\le rF_3(n)+(2r+74)(n-4)!.
$$

Choosing the largest admissible multiple of six gives the stated upper
error estimate. The lower estimate
`L(n) >= F3(n) + 2(n-4)! - 2(n-5)!`, whose full proof dependencies are
included, supplies the other side. The formal theorem concerns the minimum
length of actual covering words. It has no assumed source-family existence
or numerical recurrence premise.

The main declarations are in the namespace `CoefficientTwoPrecision`:

| Declaration | Result |
| --- | --- |
| `finite_covering_word` | An actual word with the finite bound above |
| `shortest_length_error` | An explicit two-sided normalized error estimate |
| `shortest_length_asymptotic` | The displayed asymptotic formula for the minimum length |

[StatementAudit.lean](lean/Quantitative/StatementAudit.lean) prints their
elaborated types, the original coverage and minimum-length definitions, and
the axioms they use. [The saved statement output](verification/final-statements.txt)
allows inspection without building the project.

- `lean/`: the complete local proof closure, dependency pins, and guarded runners.

and [Halfar's superpermutation work](https://github.com/jhalfar/superpermutations).
